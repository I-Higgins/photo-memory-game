Notes for Claude Code

Follow exactly

  • Colour, type, radius and timing values from tokens.css. Don’t add new colours.
  • No timers, scores, move counters, lives, “wrong” colours, buzzes or game over, anywhere.
  • Card grid table and the size formula (Layout board). Cards stay between 4:5 and 5:4.
  • Cards centre-crop (object-fit: cover). The match moment is never cropped (contain).
  • Player controls at least 60 px tall, the main action 72, helper 48, never below 44. Every icon has a visible text label.
  • Back / Hint / Restart sit outside the card area with clear space. Restart always asks first.
  • The helper area opens only by a 2 s press-and-hold or a 4-digit code. Delete always confirms and names what is lost.
  • A still version of every animation (Motion board), switched by prefers-reduced-motion.
  • Read aloud is off by default. When it’s off, its button doesn’t render at all (no empty gap).
  • Photos stay on the device: no network calls with photo data, no analytics.
  • Real buttons, links, labelled inputs, role="switch" / radiogroup, visible 4 px focus ring.
  • Original artwork only: the SVGs on the artwork boards, no icon fonts or brand marks.

Your call

  • File structure, state handling and routing (hash routes are fine).
  • How photos are stored: IndexedDB suggested. Resize on import to a 1600 px long edge (JPEG ~0.82) plus a 600 px thumbnail for cards. Call navigator.storage.persist() after the first album.
  • Backup format: one .zip holding a manifest JSON (album, captions, order, cover) and the images. Use the share sheet / download on iPad.
  • Shuffle: any fair shuffle. Never repeat the exact same layout twice in a row.
  • Which unmatched pair the hint picks. Suggested: the partner of a turned-up card, else the pair seen most often.
  • Copy can be tightened, as long as it stays plain, short and kind.
  • Service-worker strategy, as long as the app works fully offline after one online visit and shows the update banner.
  • Exact easing curves within ±60 ms of the given durations.
  • iPhone layouts beyond what’s drawn (lower fidelity was agreed).
